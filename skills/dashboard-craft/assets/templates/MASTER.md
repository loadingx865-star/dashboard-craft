## 3. 缩放策略（Gate 必填）

选定一种，并写清边界条件：

- [ ] 等比缩放：设计稿尺寸 `____ × ____`，超宽/超高时的处理是 `____`
- [ ] 断点重排：断点档位见下表
- [ ] 混合：外层缩放范围 `____`，内部重排触发条件 `____`

| 断点 | 最小宽度 | 布局变化 | 字号处理 |
|---|---|---|---|
| laptop | 1024px | | |
| desktop | 1280px | | |
| fhd | 1920px | | |
| qhd | 2560px | | |
| uhd-4k | 3840px | | |

选重排：根字号方案 `html { font-size: clamp(____); }`，全部尺寸用 `rem` 派生。

## 7. 目录结构（非标准约定必填）

项目若未使用 `src/layouts`、`src/components`、`src/charts` 默认约定，
**必须在此登记真实路径**，否则阶段 3/4 的 Gate 不通过：

```
src/layouts/       布局骨架
src/components/    共享组件（唯一入口）
src/charts/        图表封装（唯一入口）
design-system/
├── MASTER.md
├── design-tokens.json
└── pages/         页面级受限偏离
```

## 8. 组件规则

- 页面禁止自造样式；一切样式经由组件与 token。
- 同类组件只有一个实现，变体通过 props 表达，不复制文件。
- 组件必须处理空 / 加载 / 错误三态。

## 9. 页面级偏离

任何偏离必须新建 `design-system/pages/<page>.md` 并写明：

```
偏离项：
原因：
影响范围：
是否临时（若是，注明移除条件）：
```

## 10. 冲突裁决顺序

`design-tokens.json` > 本文件 > `pages/<page>.md` > 现有代码。
