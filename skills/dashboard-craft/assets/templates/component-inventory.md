# 组件清单

> 单一真源之一。新需求先查此表；能用现有组件就不新造。新造组件必须登记。

## 基础组件层

| 组件名 | 用途 | 变体 | 文件路径 | 状态 |
|---|---|---|---|---|
| Button | 按钮 | primary / ghost / danger | | 稳定 |
| Tag | 状态标签 | ok / warn / alarm / offline | | 稳定 |
| Table | 数据表格 | 普通 / 虚拟化 | | 稳定 |
| Card | 容器卡片 | 普通 / 高亮 | | 稳定 |
| Icon | 图标（Lucide） | — | | 稳定 |

## 业务组件层

| 组件名 | 用途 | 变体 | 文件路径 | 状态 |
|---|---|---|---|---|
| MetricTile | 关键指标数字块 | 正常 / 告警 | | 稳定 |
| StatusCard | 设备状态卡 | | | 稳定 |
| AlarmList | 告警列表 | | | 稳定 |

## 图表层

| 组件名 | 用途 | 支持的图表类型 | 文件路径 | 状态 |
|---|---|---|---|---|
| Chart | **图表唯一入口** | line / bar / pie / gauge / scatter | | 稳定 |

> 禁止在页面中直接实例化图表库。所有图表必须通过 Chart 组件。

## 状态说明

| 状态 | 含义 |
|---|---|
| 稳定 | 可放心使用 |
| 实验 | 可用但 API 可能变化 |
| 废弃 | 禁止在新代码中使用，需迁移 |
