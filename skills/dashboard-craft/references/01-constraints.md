# 阶段 0 —— 约束锁定

## 目的

把"适配问题"从交付阶段前移到开工第一天。约束卡不做完，不允许写 UI 代码。

## 为什么这一步不能省

看板类项目的返工，绝大多数不是"技术难"，而是**一开始就没问清交付环境**。典型漏问项：

- 只按自己的笔记本（1920×1080）开发，结果现场是 4K 拼接屏，字号小到看不清。
- 没问浏览器，用了目标浏览器不支持的 API 或字体，交付当天白屏或字体乱码。
- 没问缩放，现场系统缩放 150%，布局溢出。
- 没问运行时长，7×24 连续运行几天后内存涨到崩溃。
- 没问内网，引用了外部 CDN 字体，现场加载不出来。

## 必须确认的六类约束

### 1. 显示终端

逐个列出真实终端，不要写"大屏"这种含糊描述。

| 字段 | 说明 | 示例 |
|---|---|---|
| 终端类型 | 电视 / 拼接屏 / 显示器 / 笔记本 / 平板 / 手机 | 工厂电视 |
| 型号 | 尽量具体 | 小米电视 EA75 |
| 物理分辨率 | 像素 | 3840×2160 |
| 浏览器可用宽高 | 扣掉浏览器 UI 后的实际视口 | 3840×2000 |
| 观看距离 | 影响最小字号与信息密度 | 约 3 米 |
| 交互方式 | 只读 / 鼠标 / 触摸 / 遥控 / 键盘 | 只读轮播 |

**要点**：物理分辨率 ≠ 浏览器视口。电视机开浏览器后，顶部/底部会占掉几十到上百像素，且不同浏览器差异很大。必须实测，不能推算。

### 2. 浏览器

| 字段 | 说明 |
|---|---|
| 浏览器名称与版本 | Chrome 120+ / Edge 120+ / 国产内核浏览器 |
| 内核 | Chromium 版本号（决定可用 CSS/JS 特性） |
| 无头/有头 | 现场是否可开无头（影响自动化测试） |

国产内核浏览器（如统信、麒麟、360、QQ 浏览器等）要额外确认：

- Chromium 内核是否落后（可能不支持容器查询、`:has()`、新配色函数等）。
- 是否禁用 WebGL / Canvas 硬件加速（影响大数据量图表性能）。
- 字体渲染差异（中文字体回退、字重缺失）。
- 是否强制兼容模式（可能触发 IE 内核）。

### 3. 缩放与 DPI

- 系统缩放：100% / 125% / 150% / 175%。
- 浏览器缩放：是否被现场固定。
- 设备像素比（devicePixelRatio）：影响 canvas 清晰度。

**实测建议**：用同一页面分别以 100% 和 150% 缩放截图对比，落差大的地方就是风险点。

### 4. 观看距离与可读性

观看距离决定**最小字号下限**：

| 观看距离 | 最小正文字号（经验值） |
|---|---|
| < 1 米 | 12-14px |
| 1-2 米 | 14-16px |
| 2-4 米 | 18-24px |
| > 4 米 | 24px 以上，关键数字更大 |

看板上的关键指标数字应显著大于说明文字，形成清晰层级。

### 5. 数据特性

| 字段 | 说明 | 影响 |
|---|---|---|
| 刷新频率 | 每秒 / 每分钟 / 手动 | 重渲染策略、轮询 vs WebSocket |
| 单页数据点量级 | 几十 / 几千 / 几万 | 是否需要虚拟化、降采样 |
| 运行时长 | 演示 / 8 小时 / 7×24 | 内存泄漏风险，需要长时间监控 |
| 数据来源 | 内网 API / 消息队列 / 静态文件 | 网络与鉴权策略 |

**7×24 运行是硬约束**：必须安排长时间运行测试，监控内存与定时器泄漏。

### 6. 网络与环境

- 是否内网隔离（决定字体、图标、依赖是否必须本地化）。
- 带宽上限（影响首屏加载与图片策略）。
- 是否允许外部 CDN（内网通常禁止）。
- 是否有反向代理、跨域策略。

## 产出：环境约束卡

复制 `assets/templates/constraints-card.md` 填写，作为项目第一份文档，纳入版本管理。

## Gate 检查

进入阶段 1 前，逐条确认：

- [ ] 所有真实终端已列出，且分辨率经过实测
- [ ] 目标浏览器及版本已确认，国产内核差异已知
- [ ] 缩放比例已确认
- [ ] 观看距离已确认，最小字号有依据
- [ ] 数据刷新频率与量级已确认
- [ ] 运行时长已确认，是否需要长稳测试有结论
- [ ] 网络与 CDN 限制已确认

任一项空白，不得进入阶段 1。**这条由脚本判定，不由 AI 自述**：

```bash
python <skill>/scripts/check_gates.py --project . --stage 0
```

脚本会检查约束卡是否存在、表格是否有空单元格、是否残留占位符与未勾选项、是否记录了真实分辨率。退出码非 0 即不得进入阶段 1。
