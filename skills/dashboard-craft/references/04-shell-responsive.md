# 阶段 3 —— 骨架先行与响应式/大屏适配

## 目的

在填任何业务内容之前，先把布局容器与响应式策略验证通过。这能把适配问题从"交付前"提前到"第一天"。

## 为什么先做骨架

如果先写页面内容再调适配，每次断点变化都会引发内容重排、组件重写、图表重调——返工量按内容量指数增长。骨架先行时，改动成本几乎为零。

## Layout Shell 应包含

```
Layout Shell
├── 顶层容器（处理缩放策略、基准视口）
├── 导航/标题栏（固定高度或自适应）
├── 内容栅格（列数随断点变化）
├── 卡片槽位（定义最小尺寸与溢出行为）
├── 全局状态区（时间、连接状态、告警提示）
└── 异常态占位（加载/空/错误/离线）
```

## 骨架验收方式

**用假数据或占位块**填满骨架，然后在全部目标分辨率下截图检查：

- [ ] 无横向滚动条
- [ ] 无元素溢出容器
- [ ] 卡片不被裁切
- [ ] 关键操作区可见且可点击
- [ ] 极小与极大分辨率下布局仍合理

这一步通过后再进入阶段 4。

## 断点设计

看板的断点不同于普通网站，需包含大屏专用档：

| 档位 | 典型宽度 | 说明 |
|---|---|---|
| 超大屏/拼接 | ≥ 2560px | 增加列数、放大字号、提升信息密度 |
| 4K 大屏 | 1920-2559px | 主设计档 |
| 普通桌面 | 1280-1919px | 减少列数 |
| 笔记本 | 1024-1279px | 可能需纵向排布 |
| 平板/兜底 | < 1024px | 明确是否支持；若不支持需给出提示页 |

**关键**：断点必须来自 stage 0 实测的真实终端，不能照抄通用网站断点。

## 大屏适配的具体手段

### 1. 单位选择

- 优先 `rem`（派生自根字号），避免散落的 `px`。
- 需要在缩放容器内保持比例的，可用 `vw/vh` 或 `cqw/cqh`（容器查询单位）。
- 慎用 `px` 硬编码：在高 DPI 大屏上会显得过小。

### 2. 等比缩放（scale）方案的正确用法与代价

"避免写死 px"与"把写死的 px 整体缩放"是**两条不同的路线**，不能同时说。先选定一条：

| 路线 | 做法 | 何时选 |
|---|---|---|
| 断点重排 | 尺寸由 `rem` / `clamp()` / 断点派生，不做整体缩放 | 终端类型多、比例差异大 |
| 等比缩放（scale） | 按固定设计稿写尺寸，外层 `transform: scale()` 统一缩放 | 终端比例固定、要求与设计稿 100% 一致 |

选 scale 路线时，以下代价必须在阶段 1 写清、在阶段 5 验证：

- **非设计稿比例**：留黑边还是裁切、裁哪一侧，先定。
- **超宽拼接（如 32:9）**：单靠 scale 会把内容压扁，通常转混合策略。
- **字体发虚**：极端缩放或非整数浏览器缩放下明显，需与现场约定浏览器缩放。
- **px 仍须来自 token**：scale 允许写设计稿 px，但 px 值必须是 token 刻度（如 `--space-16`），代码引用 token；裸写 `font-size: 13px` 依旧被硬编码门禁拦下。
- **canvas 图表补偿 DPR**：容器被缩放时按 `devicePixelRatio × scale` 提高渲染分辨率，在图表封装层统一处理。
- **字号下限仍然生效**：缩放后的实际字号须满足阶段 0 按观看距离定的最小字号。

### 3. 容器查询（Container Queries）

组件应根据**自身容器**而非视口自适应，这样同一组件放进不同尺寸卡片都能合理显示。若目标浏览器内核过旧不支持，需降级为 JS 观测（ResizeObserver）。

### 4. 长列表与虚拟化

数据行数多的表格/列表必须虚拟化，否则大屏上会卡顿。设定明确的阈值（如超过 100 行启用）。

### 5. 图表自适应

图表容器尺寸变化时必须重绘。统一在图表封装层用 `ResizeObserver` 处理，禁止每个图表各写一套。

### 6. 极端比例处理

超宽屏（如 32:9 拼接）要明确策略：拉伸、加列、还是保持内容居中两侧留空。**必须在阶段 1 定策略**。

### 7. 运行时防护

- 监听 `resize` 必须防抖（建议 100-200ms）。
- 避免在 resize 回调里做重计算。
- 长时间运行场景下，注意清理 observer、定时器、监听器。

## 常见破版原因清单

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 出现横向滚动条 | 固定宽度、负 margin、绝对定位越界 | 用 `max-width:100%`、检查溢出 |
| 文字被裁切 | 固定高度 + 大字号 | 改自适应高度或用 `clamp()` |
| 图表模糊 | canvas 未按 devicePixelRatio 缩放；scale 方案下未再乘外层 scale | 图表封装层统一处理（含 scale 补偿） |
| 缩放后错位 | 用 px 定位 + 百分比混用 | 统一单位基准 |
| 大屏上字太小 | 未按观看距离设计字号 | 见阶段 0 字号下限 |
| 拼接屏边缘被遮 | 未考虑物理边框 | 内容留安全边距 |
