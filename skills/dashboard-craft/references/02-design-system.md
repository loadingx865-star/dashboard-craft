# 阶段 1 —— 设计单一真源

## 目的

让"颜色、字号、间距、圆角、阴影、图表配色"有唯一权威来源，任何人（包括 AI）都不能凭感觉临时决定。这是解决"前后两期风格不一致"的根本手段。

## 三种做法，按可靠性排序

| 做法 | 可靠性 | 适用 |
|---|---|---|
| 只有设计稿（Figma） | 低 | 人会看走眼，AI 读不到 |
| 设计稿 + 文档描述 | 中 | 描述容易模糊，AI 会自由发挥 |
| **可机读 token + 规范文档 + 校验脚本** | **高** | 本规范要求 |

AI 只认最后一种。它读不到的颜色，它就会自己编一个。

## Token 分层：基础值 → 语义值 → 组件值

分三层，上层只能引用下层，不能跳层、不能写死。

```
基础值 (primitive)    blue-600: #2563EB      纯数值，无语义
       ↓
语义值 (semantic)     color-bg-canvas: {blue-900}
                     color-text-primary: #F8FAFC
                     color-status-alarm: #EF4444
       ↓
组件值 (component)    card-bg: {color-bg-canvas}
                     chart-series-1: {blue-500}
```

**为什么要分层**：换主题或调色时只改基础值与语义映射，组件层与页面自动跟随。若不分层，改一个主色要点遍全项目。

### 必备 token 类别

| 类别 | 必须包含 |
|---|---|
| 颜色 | 背景（画布/容器/浮层）、文字（主/次/禁用）、边框、状态（正常/警告/危险/离线）、图表色板（有序 8-12 色） |
| 字号 | 至少 6 级：超大数字 / 大标题 / 标题 / 正文 / 辅助 / 极小标注 |
| 间距 | 4 或 8 的倍数刻度，如 4/8/12/16/24/32/48 |
| 圆角 | 明确的有限几档，禁止随意值 |
| 阴影 | 有限几档，大屏通常弱化或不用阴影 |
| 层级 | z-index 分层定义（背景/内容/浮层/提示/遮罩） |
| 动效 | 时长与缓动曲线（大屏动效宜克制） |

## 大屏字号缩放策略（最重要的一条）

这是决定后期返工量的单一最大变量。三种策略，**必须在阶段 1 选定并写入真源**：

### 策略 A：等比缩放（scale 整个画布）

用一个固定设计稿尺寸（如 1920×1080），整体按比例缩放。

- **优点**：视觉与设计稿 100% 一致，实现简单。
- **缺点**：非 16:9 屏幕会出现留黑边或裁切；超宽拼接屏难以处理；浏览器字体在极端缩放下可能模糊；不适合需要真实响应式的场景。
- **适用**：单一固定终端、纯展示、比例完全确定的场景。

### 策略 B：断点重排（responsive）

按断点切换布局结构，字号用 `clamp()` 或断点调整。

- **优点**：适配各种分辨率与比例，无留边。
- **缺点**：设计与实现成本高，需要为每个断点定义布局。
- **适用**：终端类型多样（既有大屏又有笔记本）、信息密度需随屏幕变化的场景。

### 策略 C：混合（推荐用于多终端交付）

外层容器等比缩放，内部关键区域在极端分辨率下走断点重排。

- **优点**：兼顾一致性与适应性。
- **缺点**：最复杂，需要明确"哪里缩放、哪里重排"的边界。
- **适用**：同时交付工厂电视与控制室大屏、且都要精细效果的项目。

**强制要求**：选定后，所有字号与间距必须通过 token 或统一函数获取。禁止页面里出现裸 `font-size: 13px` 这类写法。

### 字号随分辨率变化的推荐做法

优先用 CSS 原生能力，避免 JS 动态计算（JS 计算易在缩放时抖动）：

- 根字号随视口变化：`html { font-size: clamp(14px, 0.9vw + 6px, 22px); }`
- 全部尺寸用 `rem` 派生自根字号。
- 仅在 CSS 无法满足时才用 JS 缩放，且需监听 `resize` 并做防抖。

## 图表规范

图表是看板风格断层的高发区。必须在真源里定死：

| 项目 | 必须定义 |
|---|---|
| 图表库 | **唯一选型**，禁止页面临时引入第二个库 |
| 色板顺序 | 系列 1..N 的固定颜色顺序，与状态色区分 |
| 坐标轴 | 轴线颜色、刻度颜色、字号、网格线显隐 |
| 图例 | 位置、字号、图标样式 |
| 提示框 | 背景、边框、字号、触发方式 |
| 数值格式 | 千分位、小数位、单位、大数缩写（万/亿） |
| 空数据 | 统一空状态样式 |
| 加载态 | 统一骨架或加载指示 |
| 错误态 | 统一错误提示样式 |
| 自适应 | 容器尺寸变化时的重绘策略 |

## 产出

```
design-system/
├── MASTER.md           全局权威规范（人读）
├── design-tokens.json  机读 token（AI 与构建读）
└── pages/
    └── <page>.md       页面级受限偏离（可选）
```

**层级检索规则**：构建某页面时，先查 `pages/<page>.md`；存在则其规则**覆盖** MASTER；不存在则只用 MASTER。禁止在页面里绕过这两层直接定样式。
